# ui

Semantische DOM-Startseite mit nativen Ankerlinks, sichtbarem Tastaturfokus und responsivem CSS. Keine Fachberechnung, Aufgabenformulare oder vorgetäuschte Erfolgsmeldungen. Schülerinput niemals als HTML einsetzen.

`m602-lab.ts` ist ausschließlich eine interne DOM-Bedienprobe für C01–C03.
Frage/Material, getrennte Rückmeldungen, Hilfen, ungeprüfte Zusätze und technische
Kontextwechsel sind sichtbar. Der Vite-Guard sperrt diese Ansicht im normalen
Produktionsbuild; die öffentliche Startseite importiert sie nicht. Keine Mission
oder Simulation. Tastatur/Touch-Emulation ersetzt keine echte Geräteprüfung.
