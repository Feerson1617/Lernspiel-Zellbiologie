# Runtime-Inhaltstests ab P01

In P00 sind keine Aufgaben als Runtime-Inhalte freigegeben. Die spätere
kontrollierte Überführung muss alle IDs, Kriterien und gültigen Alternativen
bewahren. `npm run test:content` meldet ohne solche Tests keinen Erfolg.
Die separate redaktionelle Konzeptprüfung bleibt `npm run check:spec`.
